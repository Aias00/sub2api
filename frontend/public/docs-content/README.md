# 概览

欢迎来到 cloudbase 文档中心。

这里的目标不是把页面按钮逐个解释一遍，而是给你一套能尽快上手、稳定使用、方便排障的最短路径。

## 这个平台解决什么问题

cloudbase 把多个上游 AI 服务统一成一个可控网关。

- 你只需要维护一套平台账号和一组 API Key。
- 你可以在同一个入口下切换不同模型和分组策略。
- 你可以用充值、订阅、限额和统计把成本和使用范围控制住。

## 适合谁用

- 个人开发者：希望少维护账号，快速接入模型。
- 小团队：需要共享额度、限制成员用量并查看统计。
- 运营或管理员：需要可视化管理渠道、套餐、支付和用户。

## 核心页面

### 仪表盘

用于快速查看余额、请求量、Token、响应时间和近期趋势。

### API 密钥

创建和管理面向客户端的访问密钥。多数用户第一次接入都会先来到这里。

### 调用说明

平台会根据当前 API Key 绑定的分组，生成对应的网关地址、认证头和示例代码。

### 充值/订阅

用于购买余额商品、订阅套餐，以及查看订单和支付状态。
