# cloudbase 使用指南

欢迎使用 **cloudbase**。它面向 Claude Code、Codex、Gemini CLI、Cherry Studio、Claude Desktop 等 AI 开发工具，提供统一的接入方式、计费入口与使用视图。

控制台入口：[首页](/home) / [控制台](/dashboard)

## 什么是 cloudbase？

cloudbase 的核心目标不是“再包一层 API”，而是把开发者真正反复要做的几件事收敛到一个地方：

- 用一个账号管理余额、订阅、订单和 API Key。
- 用一个网关地址接入多种客户端和工作流。
- 用分组控制不同模型、渠道、倍率和权限。
- 在仪表盘与使用记录中追踪成本、模型使用和失败请求。

如果你已经在多个客户端之间切换、维护多套 Key、或者需要把个人使用和团队使用拆开管理，cloudbase 更接近一个“统一工作台”。

## 适合谁

- **个人开发者 / 独立开发者**：希望用统一 Key 管理 Claude Code、Codex、Gemini CLI。
- **小团队 / 创业团队**：希望分组管理订阅、权限和成本。
- **需要稳定调用入口的集成方**：希望把客户端接到统一网关，而不是直连多个上游。

## 核心功能

### 统一 API Key

控制台创建的 API Key 可以复用在多个工具里。你可以按用途拆分：

- 本地开发一个 Key
- 自动化脚本一个 Key
- 团队共享工具一个 Key

这样更方便做停用、审计和成本归因。

### 分组驱动的模型与权限

cloudbase 不是把“所有模型”平铺给所有用户，而是通过分组来组织能力：

- 某个 Key 绑定哪个分组，就决定它能访问哪些模型
- 分组还会影响倍率、额度与一些平台能力
- 普通用户可以在控制台查看自己当前 **可用分组**

### 调用说明与快速配置

控制台 **调用说明** 页面会根据当前 Key 和分组生成：

- Base URL
- 认证头
- 推荐模型
- 示例调用方式

接入时应以控制台页面为准，而不是复制旧示例。

### 余额、订阅与订单

平台支持余额商品、订阅套餐和订单管理。用户看到的内容取决于管理员配置和当前站点开放状态。

### 用量与成本可视化

你可以在仪表盘、使用记录和 Key 用量页中查看：

- Token 使用趋势
- 模型消耗
- 失败请求
- 余额变化

## 推荐上手路径

### 1. 注册并登录

打开 [注册页面](/register)，使用邮箱或已启用的第三方登录方式创建账号。

### 2. 获取额度

进入 [充值/订阅](/purchase) 页面，选择当前站点已开放的商品或套餐。

### 3. 查看可用分组

进入控制台里的 **可用分组**，先确认当前账号能使用哪些平台和分组。
这一步能帮助你理解为什么某些模型可见、某些模型不可见。

### 4. 创建 API Key

进入 **API 密钥** 页面创建新 Key，并为不同工具分配独立 Key。

### 5. 进入调用说明

根据选定的 Key 查看网关接入方式，再去配置客户端。

### 6. 选择工具接入

按你当前的使用方式选择对应指南：

- [Claude Code 快速开始指南](quickstart/claude-code)
- [Codex 快速开始指南](quickstart/codex)
- [Gemini CLI 快速开始指南](quickstart/gemini-cli)
- [Cherry Studio 快速开始指南](quickstart/cherry-studio)
- [Claude Desktop 第三方 Provider 配置指南](quickstart/claude-desktop)

## 获取帮助

如果接入过程中出现问题，优先准备这些信息：

- 当前使用的工具和版本
- 控制台调用说明页中的 Base URL
- 报错截图或终端日志
- 使用的模型名称
- 请求发生时间

不要在聊天、工单或截图中泄露完整 API Key。
