# Claude Code 与 Codex 协同开发

Claude Code 和 Codex 都可以处理代码任务，但适合的分工不同。通过 cloudbase 统一接入后，你可以按任务类型选择工具，同时保留统一的成本统计。

## 推荐分工

- Claude Code：适合长上下文理解、需求梳理、复杂重构讨论。
- Codex：适合在本地仓库内快速修改、运行测试、处理 CI 或小范围修复。

## 协同流程

1. 用一个工具分析问题并产出计划。
2. 用另一个工具执行小范围修改。
3. 回到第一个工具做设计或边界复核。
4. 最后统一运行测试并检查 diff。

## Key 管理

建议分别创建：

- `claude-code-local`
- `codex-local`
- `vscode-helper`

这样可以在使用记录里看出不同工具的消耗情况。

## 风险控制

- 不要让多个工具同时修改同一批文件。
- 不要把管理员 Key 放进客户端共享配置。
- 大范围重构前先提交当前稳定状态。
