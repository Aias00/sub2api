# VS Code 图形化操作教程

VS Code 适合配合 Codex、Claude Code 或其他 AI 编码工具使用。图形化界面能降低文件浏览、差异检查和测试运行的门槛。

## 推荐工作流

1. 用 VS Code 打开项目目录。
2. 用内置终端启动 AI 工具。
3. 让 AI 先阅读项目结构并给出计划。
4. 修改完成后在 Source Control 面板检查 diff。
5. 运行测试或构建命令。
6. 确认无误后再提交。

## 查看改动

VS Code 左侧 Source Control 会列出变更文件。逐个打开 diff，重点检查：

- 是否修改了无关文件。
- 是否泄露 API Key。
- 是否删除了必要逻辑。
- 是否只改了样式却影响了交互。

## 处理冲突

如果 AI 修改和你手动修改冲突，不要直接全部接受。先理解两边意图，再合并需要的部分。

## 建议

让 AI 每次只处理一个明确问题。复杂任务拆成多个小提交，更容易审查和回滚。
