# 业务能力使用指南

cloudbase 除了统一 API Key、模型分组和计费能力，也提供面向内容生产与业务流程的前台能力。当前重点能力包括微信导出、热点追踪、图片提示词库、生图工作台和我的任务。

业务入口：[首页](/home) / [微信导出](/wechat) / [热点追踪](/hot) / [图片提示词](/prompts) / [生图工作台](/image-generator) / [我的任务](/tasks)

## 能力总览

### 微信导出

微信导出用于把公众号文章沉淀为可下载产物。它适合归档文章、整理素材、交付运营资料，或把公众号内容转入后续编辑流程。

主要能力：

- 绑定或同步公众号文章。
- 选择文章后创建导出任务。
- 支持 HTML、Markdown、JSON 等格式组合，具体可选项以页面配置为准。
- 导出任务完成后在任务列表中下载产物。

### 热点追踪

热点追踪用于集中浏览近期热点流。它适合选题、运营观察和内容策划前的素材扫描。

当前页面聚焦热点流本身，不再把热点拆成多个左侧分类工作区。你可以直接浏览主列表，结合标题、来源和时间判断是否进入后续内容生产。

### 图片提示词

图片提示词库用于沉淀可复用的图像生成提示词。它适合把已有案例、风格模板和参数化表达变成团队可复用资产。

常见用途：

- 搜索现成提示词。
- 按标签、来源、模型或主题筛选案例。
- 复制提示词用于外部工具。
- 直接跳转到生图工作台继续生成。

### 生图工作台

生图工作台用于创建图片生成任务并管理生成产物。它面向真实任务队列，而不是一次性的前端演示。

主要能力：

- 输入提示词、反向提示词和风格描述。
- 选择模型、尺寸、质量和批量数量。
- 创建生图任务后等待 worker 处理。
- 查看任务状态、预览图片、下载原图。
- 对失败任务进行重试，或取消仍在队列中的任务。

### 我的任务

我的任务是统一任务中心，会集中展示微信导出和生图任务。

你可以在这里：

- 查看全部任务、进行中任务、已完成任务和需关注任务。
- 按任务类型筛选微信导出或生图任务。
- 打开原业务页面查看上下文。
- 下载完成后的产物。
- 对失败或可重试任务执行重试。

## 推荐工作流

### 内容归档：微信文章到本地资料

1. 打开 [微信导出](/wechat)。
2. 登录并同步公众号文章。
3. 搜索或选择需要导出的文章。
4. 选择导出格式并创建任务。
5. 打开 [我的任务](/tasks)，等待任务完成。
6. 下载导出包并交给后续编辑、归档或发布流程。

如果导入文章时遇到微信验证页，请优先通过公众号同步方式导入。直接粘贴链接遇到验证页时，平台会提示使用公众号同步，避免把验证页误当文章写入。

### 选题生产：热点到提示词再到图片

1. 打开 [热点追踪](/hot)，浏览近期热点。
2. 记录适合做内容的主题、关键词和表达角度。
3. 打开 [图片提示词](/prompts)，搜索相关主题或风格案例。
4. 复制提示词，或点击“去生图”进入 [生图工作台](/image-generator)。
5. 根据热点主题调整提示词，创建生图任务。
6. 在 [我的任务](/tasks) 中查看状态并下载成图。

### 图像生产：从模板到任务产物

1. 打开 [图片提示词](/prompts)。
2. 选择一个接近目标风格的提示词。
3. 点击“去生图”，提示词会带入 [生图工作台](/image-generator)。
4. 调整模型、尺寸、质量和批量数量。
5. 提交任务后等待生成完成。
6. 预览图片，确认效果后下载原图。

## 状态说明

任务中心会把不同业务任务统一成相近状态：

- **排队中**：任务已创建，等待 worker 处理。
- **运行中**：worker 正在处理任务。
- **已完成**：任务成功完成，可以打开或下载产物。
- **部分完成**：部分文章或产物成功，部分失败，需要查看错误信息。
- **失败**：任务未完成，可以根据错误信息修改输入或重试。
- **已取消**：任务已被取消，不会继续处理。

## 使用建议

- 为不同场景保留清晰命名和记录，例如导出任务对应的公众号、文章主题或日期。
- 生图提示词尽量明确主体、风格、构图、尺寸和限制条件。
- 遇到失败任务时，先看任务列表中的错误信息，再决定重试还是修改输入。
- 下载产物前确认任务状态为已完成或部分完成。
- 不要在截图、工单或聊天中泄露账号、Cookie、API Key 或公众号敏感信息。
