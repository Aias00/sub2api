# cloudbase 使用指南

这篇指南面向第一次接触 AI 编码工具和 API 网关的用户。你不需要先理解所有概念，按顺序完成账号、额度、API Key 和工具配置即可开始使用。

## 一、为什么需要 cloudbase

Claude Code、Codex、Cherry Studio、Claude Desktop 等工具都可以连接大模型，但它们通常需要你分别处理账号、Key、网络、额度和账单。

cloudbase 的作用是把这些重复工作收敛到一个控制台：

- 统一管理 API Key。
- 统一查看余额和消费。
- 统一配置模型渠道和分组。
- 统一给不同工具提供调用地址。

## 二、这些工具分别是什么

### ChatGPT 和 Claude

它们是面向对话的 AI 产品，适合问答、写作、分析和代码辅助。

### Codex 和 Claude Code

它们更偏向开发者工作流，可以读取项目文件、执行命令、修改代码，并围绕一个工程持续迭代。

### Cherry Studio 和 Claude Desktop

它们是桌面客户端，适合把多个模型、知识库或工具能力放在一个图形界面里管理。

## 三、什么是终端

终端是输入命令的地方。很多开发工具需要通过终端启动或配置。

常见打开方式：

- macOS：打开 Terminal 或 iTerm2。
- Windows：打开 PowerShell 或 Windows Terminal。
- Linux：打开系统自带 Terminal。

如果文档里出现 `node -v`、`npm -v`、`codex` 这类内容，通常就是在终端里执行。

## 四、什么是 API

API 可以理解为程序之间的调用入口。你在工具里填入的 Base URL 和 API Key，就是告诉工具“去哪里请求模型、用什么身份请求”。

在 cloudbase 中常见配置包括：

- Base URL：控制台调用说明页展示的网关地址。
- API Key：你在 **API 密钥** 页面创建的密钥。
- Model：你要调用的模型名称。

## 五、开始使用

### 第 1 步：注册账号

访问 [注册页面](/register)，使用邮箱或已开放的第三方方式注册。

### 第 2 步：充值或订阅

进入 [充值/订阅](/purchase) 页面选择商品。商品列表由管理员配置，配置一个就展示一个。

### 第 3 步：创建 API Key

进入 **API 密钥** 页面，创建一个密钥。建议给 Key 起一个能看出用途的名称，例如 `local-codex` 或 `cherry-studio`。

### 第 4 步：打开调用说明

进入 **调用说明** 页面，选择刚创建的 API Key，复制页面展示的 Base URL、认证头和示例。

### 第 5 步：配置工具

根据你使用的工具阅读对应快速接入文档。配置完成后，先发送一个小请求验证连通性，再进行长任务或高成本调用。

## 六、遇到报错怎么排查

先不要反复重试高成本请求。按下面顺序检查：

1. API Key 是否完整复制，前后是否多了空格。
2. Base URL 是否来自当前站点的调用说明页。
3. 账号余额或订阅是否可用。
4. 当前模型是否在绑定分组中开放。
5. 本地代理或网络是否拦截了请求。
6. 工具日志里是否有 401、403、404、429、5xx 等状态码。

## 七、常见状态码

- `401`：认证失败，通常是 API Key 错误或已停用。
- `403`：当前账号、Key 或分组没有权限。
- `404`：Base URL 或模型名称不正确。
- `429`：触发频率限制或上游限流。
- `5xx`：平台或上游服务异常，可以稍后重试并保留日志。

## 八、安全建议

- 不要把 API Key 提交到 Git 仓库。
- 不要在截图里暴露完整密钥。
- 给不同工具使用不同 Key。
- 怀疑泄露时立即停用旧 Key 并创建新 Key。
