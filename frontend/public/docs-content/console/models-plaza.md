# 模型广场

模型广场是当前站点公开展示的模型目录页，对应页面通常是 `/models`。

它的作用不是替代控制台，而是帮助你在登录前或接入前快速判断：

- 当前站点主打哪些模型
- 每个模型更适合什么场景
- 有哪些公开的能力标签和价格信息

## 模型广场和分组的关系

要注意一点：

- 模型广场是**公开展示层**
- 分组才是**实际授权层**

也就是说，某个模型在模型广场上可见，不代表你当前账号的 Key 一定已经能调用它。  
真正是否能用，还是要看：

- 你的账号可用分组
- 你的 Key 绑定分组
- 当前站点的开放策略

## 适合用来做什么

### 登录前预览

如果你只是想先判断这个站点适不适合你的工作流，模型广场是最快的入口。

### 团队内部对齐

团队成员经常会问：

- 我们这里主推哪个模型？
- 日常开发用哪个？
- 哪个适合复杂推理？

模型广场能提供一个统一答案。

### 配置前筛选

在去配置 Claude Code、Codex、Gemini CLI 之前，你可以先看这里，再决定要不要继续购买或创建对应 Key。

## 什么时候不要只看模型广场

如果你已经登录，并且准备真正开始调用：

1. 看 [可用分组](./available-groups)
2. 创建或检查 [API 密钥](./api-keys)
3. 再去控制台的调用说明页面拿接入参数

这样才是完整链路。

## 模型广场里的信息是怎么来的

模型广场内容来自后台配置，而不是前端写死。  
所以你看到的：

- 名称
- 标签
- 描述
- 价格文案

都可能随站点配置调整。
