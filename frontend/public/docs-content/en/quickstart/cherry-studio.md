# Cherry Studio Quickstart

Cherry Studio can manage multiple model providers. Add cloudbase as a custom provider to use the same balance and API keys from your console account.

## Add provider

```text
Name: cloudbase
API Key: your cloudbase API key
API Base: value from API Guide
Model: model enabled by the selected group
```

Field names may vary between client versions. Look for Base URL, Endpoint, API Base, and API Key.

## Verify

Create a new conversation, select the cloudbase provider, and send a short message. Then check usage records in cloudbase.
