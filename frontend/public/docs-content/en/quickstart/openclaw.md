# OpenClaw Quickstart

OpenClaw-style clients usually support custom providers. Point the provider to the cloudbase gateway.

## Fields

```text
Provider: cloudbase
Base URL: value from API Guide
API Key: cloudbase API key
Model: model enabled by the selected group
```

## Flow

1. Create an API key dedicated to OpenClaw.
2. Open **API Guide** and confirm the group and model.
3. Add a cloudbase provider in OpenClaw.
4. Save and send a test message.

Use a separate key for each client so usage records remain clear.
