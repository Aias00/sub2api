# 常见问题

## 分组卡片上的倍率是什么意思？

倍率是平台用于计算余额消耗的策略参数。它通常会结合上游模型价格、渠道成本和服务策略一起生效。

简化理解：

```text
实际扣费 = 模型基础成本 × 分组倍率
```

不同分组可能面向不同模型、速度、稳定性或成本策略。实际可用分组以控制台展示为准。

## 实际扣费怎么查看？

进入 **使用记录** 页面，按时间、模型或 API Key 查看请求明细。仪表盘展示的是汇总趋势，使用记录更适合排查单次请求成本。

## 不同分组应该怎么选？

如果你刚开始使用，优先选择默认或推荐分组。只有在明确需要更低成本、更高稳定性或特定模型时，再切换到其他分组。

## 可以创建多个 API Key 吗？

可以。建议按用途拆分：

- 本地开发一个 Key。
- 自动化脚本一个 Key。
- 团队共享工具一个 Key。

这样后续可以单独停用异常 Key，也能更准确地看用量。

## 服务稳定性如何保障？

cloudbase 通过渠道管理、分组策略和调用统计来降低单一上游异常带来的影响。你仍然应该在自己的工具或脚本中保留重试、超时和降级策略。

## 如何购买余额或订阅？

进入 [充值/订阅](/purchase) 页面。页面会按管理员配置展示可购买商品；如果没有商品，说明当前站点尚未开放对应套餐。

## 支持发票吗？

发票和收据能力取决于当前站点运营配置。如果你需要开票，请联系站点管理员并提供订单号、金额和开票信息。

## 登录或支付异常怎么办？

请先记录：

- 账号邮箱。
- 发生问题的页面地址。
- 操作时间。
- 浏览器控制台或支付平台返回的错误。

如果涉及支付，不要重复提交大量订单；先确认订单状态或联系管理员处理。
