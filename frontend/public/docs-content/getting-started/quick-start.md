# 快速开始

如果你只想尽快调用成功，按下面的顺序走就够了。

## 第一步：登录并检查账号状态

- 确认你已经能够正常登录平台。
- 如果管理员开启了邮箱验证或 2FA，先完成安全校验。
- 登录后先看一眼仪表盘余额和订阅状态，避免后面调试时被额度问题干扰。

## 第二步：创建一个 API Key

进入 `API 密钥` 页面，创建一把新的密钥。

建议：

- 每个项目单独一把 Key，便于追踪和回收。
- 命名时带上环境或用途，例如 `web-prod`、`agent-dev`。

## 第三步：确认分组绑定

平台返回的调用能力取决于 Key 当前绑定到哪个分组。

- 如果你看不到预期模型，先检查分组是否正确。
- 如果管理员限制了可绑定分组，普通用户只能在允许范围内选择。

## 第四步：复制网关调用参数

进入 `调用说明` 页面，选择刚刚创建的 Key。

你会看到：

- 网关地址
- 鉴权头
- curl 示例
- 针对当前分组生成的调用片段

## 第五步：发起第一次请求

建议优先用 curl 或 Postman 验证，再接入正式代码。

```bash
curl https://your-domain.example/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {"role": "user", "content": "Hello"}
    ]
  }'
```

## 如果请求失败，先查什么

### 401 或 403

- Key 无效
- Key 被禁用
- 当前分组没有调用目标模型的权限

### 余额或套餐相关错误

- 余额不足
- 订阅额度已经耗尽
- 支付还未到账

### 模型或路由相关错误

- 当前分组未绑定目标模型
- 上游渠道异常
- 分组调度策略与预期不一致
