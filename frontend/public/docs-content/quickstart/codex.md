# Codex 快速开始指南

Codex 适合在本地项目中完成代码阅读、修改、测试和提交前检查。接入 cloudbase 后，可以用平台统一管理额度和 Key。

## 准备工作

- 已安装 Codex 或你正在使用的 Codex 客户端。
- 已创建 cloudbase API Key。
- 已从 **调用说明** 页面获取 Base URL。

## 配置方式

不同 Codex 客户端的配置入口不同，常见字段含义一致：

```text
Base URL: 以 cloudbase 调用说明页为准
API Key: 你的 cloudbase API Key
Model: 当前分组开放的模型
```

如果客户端支持环境变量，可以将 Key 放在终端环境中；如果支持配置文件，建议只把密钥写入本机私有配置，不要提交到仓库。

## 使用建议

- 第一次接入先用小项目验证。
- 对大改动先要求 Codex 读取项目结构并给出计划。
- 执行命令前确认它不会删除数据或泄露密钥。
- 让 Codex 在完成后运行测试并报告结果。

## 排查

如果 Codex 没有走 cloudbase，通常是 Base URL 没配置成功，或客户端仍在读取旧配置。重启终端和客户端后再试。
