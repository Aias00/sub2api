账号安全配置主要集中在个人资料页。

## 密码管理

建议：

- 使用单独密码，不与其他站点复用
- 修改密码后同步清理旧客户端里的缓存凭证
- 如果你怀疑账号泄漏，先改密码，再轮换 API Key

## 双因素认证（2FA）

2FA 开启后，登录除了密码之外，还需要验证器动态码。

### 开启前要确认

- 当前服务器已经正确配置固定的 `TOTP_ENCRYPTION_KEY`
- 你使用的验证器 App 时间同步正常
- 你知道如何保管恢复方式或重新绑定流程

### 如果验证码一直不通过

优先排查：

- 手机时间是否自动同步
- 服务器是否最近重启并更换过 TOTP 加密密钥
- 当前绑定是不是历史旧配置遗留下来的失效条目

### 重新绑定

如果旧绑定失效，最稳妥的方式通常是：

1. 由管理员重置当前账号的 2FA 状态
2. 重新进入绑定流程
3. 用新的二维码重新扫码

## 资料维护

个人资料页可以维护的内容通常包括：

- 昵称
- 邮箱绑定
- 头像
- 余额通知邮箱

如果某个第三方身份来源未开放，对应卡片会被隐藏，而不是显示一个无法操作的空状态。
